# Klonex

Portfolio of Olalekan Ayorinde (Klonex), visual and motion designer in Lagos.

Static site: `index.html` with inline CSS and JS; resume in `docs/`.
To add a video to a project, set `video` (and `poster`) on that project in the `P` list; for the showreel, put a `<video>` inside `#reel`.

Made by Àmúró & Klaus.
